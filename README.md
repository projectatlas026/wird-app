# وِرد - User Testing Build v0.1

مرحباً بك في النسخة التجريبية الأولى من تطبيق **وِرد**.

## طريقة التشغيل (Windows)

1. تأكد من تثبيت [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث).
2. استخرج محتويات الملف ZIP في مجلد جديد.
3. افتح واجهة الأوامر (PowerShell أو CMD) داخل المجلد.
4. نفذ الأوامر التالية بالترتيب:
   ```bash
   npm install
   npm run dev
   ```
5. افتح الرابط الذي سيظهر لك (غالباً `http://localhost:5173`).

## أدوات الاختبار

تم دمج أدوات خاصة لتسهيل عملية التجربة:
- **وضع الاختبار**: عند تفعيله، يتم استخدام قاعدة بيانات منفصلة تماماً عن بياناتك الحقيقية.
- **محاكاة الزمن**: يمكنك تقديم تاريخ التطبيق يوماً واحداً لاختبار ظهور المهام المتأخرة والمراجعات.
- **زر الملاحظات**: موجود في أسفل الشاشة لنسخ تقرير الخطأ ومشاركته مع المطور.

## الميزات قيد الاختبار في هذا الإصدار
- محرك إنشاء الخطة (حفص فقط).
- نظام النطاقات (أجزاء، أحزاب، سور، آيات).
- إدارة المهام اليومية والمتأخرة.
- إعادة الجدولة (النقل للتعويض والتوزيع).

## مشكلات معروفة
- دعم رواية ورش وقالون لا يزال قيد العمل (سيظهر "قريباً").
- نظام المراجعة المتباعدة (SRS) مدمج برمجياً ولكن يحتاج واجهة إحصائيات.
